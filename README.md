## 🚨 Project Flow

Emergency Detection  
↓  
Traffic Analysis  
↓  
Optimal Route  
↓  
Signal Coordination  
↓  
Emergency Corridor  
↓  
Hospital Arrival  
↓  
Corridor Deactivation

## ⚠️ Note

This is a prototype project. Traffic, route, signal, and ETA values are simulated. YOLO currently detects general vehicle classes; a dedicated ambulance-trained model would be used for production.
